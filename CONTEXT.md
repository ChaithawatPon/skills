# Context

## Ubiquitous Language

- Catalog: the top-level public repository `ChaithawatPon/skills`.
- Package: one installable skill directory under `skills/<category>/<name>/`.
- Skill: the agent workflow described by a package's `SKILL.md`.
- Category: an ASCII folder under `skills/` that groups packages by workflow.
- Display name: the human-facing Thai category name used in README and docs.
- Approval gate: a rule that requires Pon's explicit approval before a public,
  account, marketplace, profile, or deletion action.
- Privacy boundary: the rule that keeps private setup, account data, runtime
  output, screenshots, and personal data out of this public catalog.
- Validation: local and CI checks that scan structure, tests, and public safety.
