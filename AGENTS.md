# AGENTS.md

Public skill monorepo for `ChaithawatPon/skills`.

- Each installable skill lives under `skills/<name>/` with its own `SKILL.md`.
- Do not copy private skills, browser state, inventory, credentials, or local
  runtime output into this repository.
- Standalone public skill repositories remain the versioned release sources
  until an explicit redirect is approved.
- The GitHub profile README is a public index. This repository is the
  installable catalog.
- Validate before release: `bash scripts/validate.sh`.
