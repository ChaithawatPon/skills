# Find Place to Eat

1. Extract the dish or cuisine, location, travel radius, budget, desired time, group size, and dietary needs. Ask one question only when a missing detail materially changes the result.
2. Search current map and web results. Use social pages or delivery platforms as supporting evidence for a specific dish, current menu, price, or opening status.
3. Verify each serious candidate's exact branch, address, rating and review count, hours, price evidence, requested dish, direct map URL, and recent-review signals.
4. Rank one best choice and up to two backups by dish match, distance, current availability, price, review quality, and travel practicality. Label each `go`, `backup`, or `skip`.
5. Return direct map links, the key reason for each choice, unresolved risks, and one next action. Capture a tight evidence screenshot only when it excludes account details, notifications, and unrelated results.

Do not assume every branch of a chain has the same menu. Mark stale hours, closure signals, unclear prices, and mismatched dish photos as risks. Prepare directions or reservation text freely; call, message, reserve, order, or share personal details only after explicit approval of the venue and action.
