# Find Item

Find a current shortlist that helps the user decide what to buy.

1. Extract the item, maximum budget, required capability, location or pickup radius, and deal breakers. Ask one question only when a missing detail changes the search materially.
2. Search current marketplaces and reputable stores. Open every serious candidate and verify the exact model, price, condition, included accessories, location, listing freshness, seller identity signals, and direct URL.
3. Rank one best choice and up to two backups by requirement fit, total cost, evidence quality, condition, seller credibility, and pickup practicality. Give each a `buy`, `negotiate`, or `skip` decision.
4. Return direct links, verified facts, unresolved risks, and one next action. When useful, capture one tight screenshot that excludes account details, messages, notifications, and unrelated listings.

Treat conflicting details, implausible prices, deposit demands, stock-photo-only listings, and missing condition proof as risk signals. Prefer in-person inspection before payment for expensive or second-hand items. Draft messages freely; contact, reserve, order, pay, or submit personal details only after explicit approval of that recipient and action.
