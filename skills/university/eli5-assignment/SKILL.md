# ELI5 Assignment

Read one verified assignment brief or lecture file collected by `$check-assignment`. If source identity or contents are incomplete, identify the missing information and stop.

Create a self-contained HTML artifact: large useful pictures, large type, and few words. Explain only source-backed facts:

- what the task is asking for;
- absolute due date, or `Not stated`;
- grading/rubric, or `Not stated`;
- required deliverables;
- the smallest first action the student can take now.

Include a visible `Missing information` block. Cite the verified source file and URL inside the artifact. Never create answers, invent assignment facts, or submit anything. Open the HTML locally. External sharing requires separate approval.
