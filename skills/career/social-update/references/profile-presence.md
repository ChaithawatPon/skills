# Profile and portfolio workflow

Use this module for LinkedIn, GitHub, X, Facebook, Instagram, a freelance
marketplace, or another public professional profile.

1. Confirm the exact platform, account, current public fields, and requested
   outcome. Stop for account mismatch, login, CAPTCHA, MFA, recovery, identity,
   tax, bank, or payment fields.
2. Build a claim-to-evidence table from current public repositories, shipped
   work the user owns, an approved resume, and user-provided proof. Private
   evidence may support the current decision but does not become publishable.
3. Propose complete before/after values for only the named fields. Keep copy
   role-focused and exclude location, routines, schedules, contact details, and
   private affiliations unless the user explicitly supplies and approves that
   exact field value.
4. Apply only after approval of the unchanged target and replacement text.
5. Reload the direct public profile and verify every approved field and its
   visibility. Report partial or failed updates honestly.

Profile approval never authorizes a post, message, application, follow, delete,
or change on another platform. Let the user enter sensitive account fields
privately; never copy them into notes, logs, screenshots, or packets.
